Attention Is All You Need · §3.5

Positional encoding

How a sequence of tokens gets a sense of order, using nothing but sine and cosine.

PE(pos, 2i)  =  sin( pos / 100002i/512 )
PE(pos, 2i+1) = cos( pos / 100002i/512 )

The frequency stack

Each column pair (sin, cos) is one wave. Column pair i=0 is the fastest wave — it turns quickly and repeats within a few positions. Column pair i=255 is the slowest — across an entire page of text it barely moves off its starting value. Ten representative waves, positions 0–40:

faster → more columns cycle per position slower → nearly flat across a full page

Why sin and cos come as a pair

Plot (sin θ, cos θ) as one point and it traces a circle as θ grows — this is exactly what one sin/cos column-pair does as pos increases. The pairing means position isn't stored as a single number, it's stored as an angle — a direction on a circle.

That's what makes the fixed-offset trick work: rotating a point on a circle by a fixed extra angle always lands you at the same kind of relationship, no matter where you started. So "3 positions later" looks geometrically identical whether you're at position 5 or position 500 — a pattern a linear layer can learn to detect directly.

Added, not appended

Sin/cos values never leave −1 to 1, so adding this matrix onto the word embedding nudges every row's position in 512-dim space without overwhelming the meaning already sitting there. Concatenating instead would grow the vector past 512 and break every layer downstream that expects exactly that width.

d_model = 512  ·  i runs 0…255, one sin/cos pair per i  ·  base = 10000 (chosen by the paper's authors)
